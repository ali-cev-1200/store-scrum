# Product Backlog

هدف محصول: یک اپلیکیشن فروشگاهی اندروید (Jetpack Compose) که کاربر بتواند محصولات را ببیند، به سبد خرید اضافه کند و سفارش ثبت کند.

- اولویت: **M** = Must، **S** = Should، **C** = Could
- تخمین با Story Point (دنبالهٔ فیبوناچی: 1، 2، 3، 5، 8)
- قالب هر Story: «به‌عنوان … می‌خواهم … تا …»

## Epic A — زیرساخت پروژه

| ID | User Story | اولویت | SP | اسپرینت |
|---|---|---|---|---|
| US-01 | به‌عنوان توسعه‌دهنده می‌خواهم ساختار پروژه، Gradle و کتابخانه‌ها آماده باشد تا بتوانم توسعه را شروع کنم. | M | 3 | 0 |
| US-02 | به‌عنوان کاربر می‌خواهم ظاهر اپ (رنگ، فونت، شکل‌ها) یکدست باشد تا تجربهٔ بهتری داشته باشم. | S | 2 | 0 |

**معیار پذیرش US-01:** پروژه بدون خطا build می‌شود؛ وابستگی‌های Compose، Navigation، Retrofit، Room، Koin، Coil و Lottie اضافه شده‌اند؛ تست نمونه اجرا می‌شود.
**معیار پذیرش US-02:** فایل‌های Theme، Color، Type و Shape تعریف شده‌اند و همهٔ صفحه‌ها از آن‌ها استفاده می‌کنند.
