# Definition of Done (DoD)

یک User Story فقط وقتی «انجام‌شده» حساب می‌شود که همهٔ موارد زیر برقرار باشد:

1. همهٔ معیارهای پذیرش Story برآورده شده باشد.
2. کد بدون خطا کامپایل شود (`gradlew assembleDebug`).
3. برای منطق جدید (Repository یا ViewModel) یونیت تست نوشته شده باشد.
4. همهٔ یونیت تست‌ها پاس شوند (`gradlew testDebugUnitTest`).
5. قابلیت روی شبیه‌ساز یا گوشی به‌صورت دستی بررسی شده باشد.
6. کد در گیت کامیت شده و شمارهٔ Story در پیام کامیت آمده باشد.
7. وضعیت Story در برد و فایل اسپرینت به‌روز شده باشد.

## Definition of Ready (DoR)

یک Story وقتی وارد اسپرینت می‌شود که:

- با قالب «به‌عنوان … می‌خواهم … تا …» نوشته شده باشد.
- معیار پذیرش داشته باشد.
- تخمین Story Point داشته باشد و از ۸ بزرگ‌تر نباشد (در غیر این صورت شکسته شود).
